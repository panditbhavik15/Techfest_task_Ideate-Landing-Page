Welcome to the 30th edition of Techfest, Asia’s largest science and technology festival.

Every December, IIT Bombay opens its gates to school and college students from across India and abroad. The programme is run entirely by students and splits into a few clear lanes: you can compete, learn, listen, exhibit, or simply come for the crowd and the noise.

Qualifiers run through zonal cities first, then the national finals converge on campus for the Grand Finale.

  • Competitions with published prize pools, from ₹45,000 to ₹25,50,000
  • Paid early-bird workshops with a professional certificate from IIT Bombay
  • Campus stay inside IIT Bombay for the duration of the fest

        Try a submission

        The six cases are shown with their expected values because this is a review. A live contest would hide them and only score the run.

        Nothing has run yet.

          Not a security boundary. This runner puts the code in a Web Worker so a submission that loops forever cannot freeze the page, and it kills the worker after 1.5 seconds per case. That is all it does: a worker has no CPU, memory, network or filesystem limits, so a real evaluator has to run each submission in a container or a seccomp jail with a clock budget, an output cap and a per-team rate limit before it can decide anything.

                Payouts: the question every winner asks afterwards

                A prize that has not landed is a support ticket with a team name on it. This is the ledger an accounts desk reads from, stage by stage, and the lookup a winner can run without writing to anyone.

                Automated prize payout tracker

                sample ledger · seven claims

                  Needs a backend. Money movement cannot live in a page: a real tracker reads from the finance system that owns the bank file, and every stage here would be an event written by that system — with the winner’s payout instrument chosen after KYC, not before. The seven claims, their stages and every figure in this table are invented for the review; prize amounts elsewhere on this page are still marked as placeholders.
